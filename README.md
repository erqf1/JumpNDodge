# JumpNDodge
JumpNDodge is a fast-paced endless dodge/runner game.
## Install
Download the installer for your platform from the **[Installer release](https://github.com/erqf1/JumpNDodge/releases/tag/installer)**:
| File | Platform |
|---|---|
| `JumpNDodge-windows-installer.exe` | Windows |
| `JumpNDodge-linux-installer.sh` | Linux |
**Windows**: run the `.exe` and follow the setup wizard. Optionally check "Create a desktop icon". On finish, JumpNDodge launches automatically. This installs to Program Files, adds a Start Menu (and optional desktop) shortcut, and includes an uninstaller.
**Linux**: `chmod +x JumpNDodge-linux-installer.sh && ./JumpNDodge-linux-installer.sh`, then answer the three prompts (install directory, create desktop/app-menu icon, launch now). This installs to `~/.local/share/JumpNDodge` by default and adds an entry to your application menu. To remove it later, run the installer again with `--uninstall`.
You only need to do this once. The installer sets up JumpNDodge's built-in updater, which then keeps the game itself current automatically on every launch — no need to reinstall for new versions.
## Prefer a portable, no-install version?
