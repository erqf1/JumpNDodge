# JumpNDodge

**Jump, dodge, survive.** A fast 2D dodge game: jump over obstacles, dodge what falls from above and survive as long as you can –
alone, with two players on one keyboard, or **online** against and with your friends.

Since version 5.0 JumpNDodge is the **Rust Edition**: starts instantly, runs at your monitor's refresh rate, stays sharp at any
scaling, has online multiplayer and updates itself. Website: [mert.win/jump](https://mert.win/jump/)

## Download

Get the latest version from **[Releases → Latest](https://github.com/erqf1/JumpNDodge/releases/latest)**:

| System | File |
|---|---|
| Windows (installer) | `JumpNDodge-windows-x64-setup.exe` |
| Windows (portable) | `JumpNDodge-windows-x64.zip` |
| Linux – Debian, Ubuntu, Mint | `jumpndodge_amd64.deb` |
| Linux – Arch, Manjaro | `jumpndodge-x86_64.pkg.tar.zst` |
| Linux (portable) | `jumpndodge-linux-x86_64.tar.gz` – run `./install.sh` for a menu entry |
| macOS Apple Silicon / Intel | `JumpNDodge-macos-apple-silicon.dmg` / `JumpNDodge-macos-intel.dmg` |
| Multiplayer server | `JumpNDodge-Server-*.zip` or Docker `ghcr.io/erqf1/jumpndodge-server` |

Or install and keep it up to date with **[W Hub](https://github.com/erqf1/whub)**.

- **Updates:** JumpNDodge checks for new versions on start and installs them with one click.
- **Coming from the old version?** The installer updates your existing installation in place – your save (`data` folder) stays.
  The old updater also moves you to the Rust Edition automatically.
- **macOS:** the app isn't notarized – on first start right-click → Open.
- **Own server:** see [mert.win/jump/server](https://mert.win/jump/server/) (port forwarding UDP 47800, Docker/CasaOS).

Older versions (including the Python version) are in **[erqf1/JumpNDodge-Archive](https://github.com/erqf1/JumpNDodge-Archive)**.
